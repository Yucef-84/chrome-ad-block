# 클린웹 · Chrome 광고 차단 확장프로그램

uBlock Origin Lite 기반의 한국어 광고 차단 확장프로그램입니다. 일반 광고 요청 차단, 한국 사이트 광고 영역 정리, 직접 숨기기와 복구를 제공합니다. 현재 버전은 **0.1.0 MVP**입니다.

## 바로 설치하기

개발자 모드에서 압축해제 확장프로그램으로 설치합니다.

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 작업 폴더의 **`dist/cleanweb`** 폴더를 선택합니다. 선택한 폴더 바로 안에 `manifest.json`이 있어야 합니다.
5. Chrome의 확장프로그램 메뉴에서 **클린웹**을 고정하고, 이미 열려 있는 웹페이지를 새로고침합니다.

설치용 ZIP을 사용하는 경우 `dist/cleanweb-0.1.0.zip`을 먼저 압축해제한 뒤 `manifest.json`이 들어 있는 폴더를 선택합니다. ZIP 파일을 Chrome 창에 끌어놓는 방식은 사용하지 않습니다.

최소 Chrome 버전은 원본 manifest 기준 122입니다. 실제 검증은 Windows의 Chromium for Testing 155에서 수행했습니다. 사용자의 기존 Chrome 프로필에 자동 설치하거나 설정을 변경하지 않았습니다.

화면 정리가 동작하지 않으면 `chrome://extensions` → 클린웹 **세부정보** → **사이트 액세스**에서 대상 사이트 접근을 허용합니다. Chrome 내부 페이지, 새 탭, 브라우저 내장 PDF 화면에는 직접 숨기기를 적용할 수 없습니다.

## 사용 방법

| 목적 | 조작 |
| --- | --- |
| 현재 사이트 차단 켜기·끄기 | 팝업의 사이트 스위치. 변경 후 자동 새로고침 |
| 남은 광고 직접 숨기기 | **남은 광고 숨기기** → 대상 클릭 → **미리보기** → **생성** |
| 선택 취소 | 선택 화면의 취소 또는 Esc |
| 잘못 숨긴 항목 복구 | **숨긴 항목 관리** → 해당 규칙 **삭제** → 웹페이지 새로고침 |
| 방금 삭제한 규칙 복원 | 관리 화면의 **방금 삭제 취소**. 설정 화면을 닫기 전 마지막 삭제 묶음에 한해 제공 |
| 사이트의 사용자 숨김 모두 삭제 | **사이트별 숨김 초기화** → 도메인 선택 → **초기화** |
| 전체 차단 일시 중지 | 설정의 전체 사이트 스위치. 다시 켜면 기존 사이트 예외와 수준 복원 |
| 기본 필터 변경 | 설정의 필터 체크박스 변경 후 대상 페이지 새로고침 |
| 상세 엔진 설정 | 설정 오른쪽 위 **고급 설정**. 원본 uBOL 대시보드 사용 |

기본 모드는 네트워크 차단과 사이트별 화면 정리를 제공하는 원본 엔진의 Optimal 수준입니다. 고급 설정에서는 더 넓은 화면 정리를 적용하는 Complete 모드 등 원본 기능을 사용할 수 있습니다. 직접 숨긴 항목은 도메인별로 저장합니다. 사이트 예외는 해당 도메인과 하위 도메인에 적용됩니다.

## 구현한 기능

- Manifest V3의 선언형 네트워크 차단과 기존 uBOL의 페이지 정리 엔진.
- 한국어 팝업·설정, 별도 이름과 아이콘.
- 기본 필터 8개: uBlock 필터, EasyList, EasyPrivacy, Peter Lowe, uBlock badware, URLhaus, YousList, 클린웹 사이트 보완.
- 디시인사이드의 왼쪽 날개·고정·하단 등 확인한 광고 컨테이너 보완.
- 원본 요소 선택기의 미리보기·저장, 사용자 규칙 검색·삭제·취소·사이트별 초기화.
- 사이트별 차단 수준, 필터 선택, 예외와 사용자 규칙의 로컬 저장.
- 소스 커밋 고정, 추가 필터 변환 보고서, 패키지 무결성 확인 및 대응 소스 ZIP.

현재 기본 정적 네트워크 규칙은 **20,408개**입니다. 포함된 정적 규칙 묶음은 58개이며 그중 8개만 기본 활성화됩니다. 전체 묶음을 동시에 활성화하지 않습니다. 필터 용량 부족과 설정 적용 실패는 UI에 표시합니다.

## 빌드

Node.js 22 이상과 Git이 필요합니다. 기본 빌드에는 npm 패키지 설치가 필요하지 않습니다.

```powershell
# 최초 소스 확보 또는 고정 버전 복구: 인터넷 필요
node scripts/bootstrap.mjs

# 고정된 원본과 추가 필터로 로컬 빌드: 다운로드하지 않음
node scripts/build.mjs

# 기능 모델 테스트와 전체 패키지 정적 검사
node --test tests/model.test.mjs
node scripts/verify.mjs

# 설치용 ZIP, 대응 소스 ZIP, SHA-256 생성
node scripts/package.mjs

# Windows .NET ZIP 라이브러리로 검사하고 실제 소스 ZIP에서 다시 빌드
node scripts/verify-package.mjs
```

`npm run bootstrap`, `npm run build`, `npm test`, `npm run verify`, `npm run package`도 같은 작업을 수행합니다.

빌드는 고정된 `vendor/ubol/chromium` 원본 패키지를 기반으로 UI를 추가하고, YousList와 로컬 보완 필터를 원본 `make-rulesets.js`로 다시 변환합니다. 글로벌 기본 목록 전체를 최신 원격 필터에서 재생성하는 방식은 아닙니다. 기본 목록의 시점은 고정된 원본 버전을 따릅니다. 추가 필터 원문을 로컬 캐시에 공급하므로 이 빌드 단계는 네트워크 다운로드 없이 실행됩니다.

### 생성 파일

| 경로 | 내용 |
| --- | --- |
| `dist/cleanweb/` | Chrome에 로드할 실제 확장프로그램 |
| `dist/cleanweb-0.1.0.zip` | 설치용 압축 파일. manifest가 ZIP 루트에 위치 |
| `dist/cleanweb-0.1.0-source.zip` | 이 버전의 프로젝트·빌드 도구·고정 vendor 소스 |
| `dist/SHA256SUMS.txt` | 두 ZIP의 SHA-256 |
| `dist/build-report.json` | 소스 버전, 추가 필터 메타데이터, 변환 문제, 패키지 파일 해시 |
| `dist/filter-build.log` | 추가 필터의 수락·변환 결과 |
| `output/playwright/` | 개발용 검증 캡처. 설치 ZIP에는 포함하지 않음 |

소스 ZIP은 `cleanweb-source/` 아래에 풀립니다. 오프라인 커밋 확인을 위해 공개 vendor 저장소의 Git 메타데이터도 포함합니다. 로컬 Git reflog와 hook, 개인 브라우저 프로필, 다운로드 캐시, 개발 캡처와 작업 폴더의 루트 Git 설정은 포함하지 않습니다. 압축해제한 소스 폴더에서 위 빌드 명령을 실행할 수 있습니다.

## 코드 구조와 업데이트

```text
src/cleanweb/           한국어 팝업·설정 및 입력 검증
filters/               직접 조사한 사이트 보완 규칙
scripts/               소스 확보·빌드·검증·패키징
tests/                 호스트·선택자·규칙 목록 모델 검증
vendor/ubol/           고정 uBOL 원본과 uBlock 하위 모듈
vendor/youslist/       고정 YousList 원문
upstream.lock.json     공개 저장소와 정확한 커밋
```

원본 엔진 코드를 직접 편집하지 않고 한국어 UI를 별도 디렉터리에 둡니다. `package.json`의 숫자 버전이 최종 manifest 버전이 됩니다. 원본을 갱신할 때는 `upstream.lock.json`의 uBOL 커밋·uBlock 하위 모듈 커밋·원본 버전 및 YousList 커밋을 함께 확인하고, bootstrap → build → verify → 실제 사이트 재검증 순서로 진행합니다.

압축해제 설치를 업데이트할 때는 설치 경로를 유지하고 같은 폴더에 새 빌드 결과를 놓은 다음 확장프로그램 화면의 **새로고침**을 사용합니다. 먼저 제거하면 저장한 규칙과 설정이 사라질 수 있습니다. 스토어 자동 업데이트는 아직 제공하지 않습니다.

## 검증 범위와 제한

디시인사이드에서 식별한 광고 영역 4개 숨김과 사이트 차단 해제 시 4개 영역 복구를 확인했습니다. 국내 사이트 총 6개의 비로그인 기본 화면, 직접 숨김과 복구, 브라우저 재시작 및 버전 변경 후 설정 보존도 확인했습니다. 상세 결과는 [VALIDATION.md](VALIDATION.md)에 있습니다.

모든 사이트·모든 광고 제거를 보장하지 않습니다. 동영상 광고, 광고 차단 탐지 우회, 계정 로그인·결제 호환성, 전체 사이트의 광고 제거율과 성능 비교는 별도 검증이 필요합니다. 현재 결과물은 직접 설치하고 검토할 수 있는 MVP이며 Chrome Web Store 공개 심사를 거치지 않았습니다.
